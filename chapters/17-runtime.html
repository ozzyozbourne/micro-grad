The scheduler (Part III) handed us a LINEAR of CALLs, and codegen (Part IV) can turn each kernel AST into source code. This chapter is the last mile: where does memory come from, who compiles and loads the code, and what exactly happens between run_linear(linear) and a CPU instruction touching your floats? 17.1Intuition: a kitchen that runs recipes

Think of the schedule as a list of recipe cards (CALLs). To cook one, a kitchen needs four things:

  • A pantry (the Allocator) that hands out containers (storage) and takes them back — and, being lazy, keeps washed containers on a shelf so the next request for the same size doesn't need a trip to the store (the LRU cache).
  • A translator (the Renderer) that rewrites the recipe in the local language (C, LLVM IR, PTX, Metal, WGSL…), and a typesetter (the Compiler) that prints it into a binary the cooks can follow.
  • A cook (the Program) that loads that binary and runs it with the given containers.
  • A manager (run_linear) who walks the card list, makes sure everything is translated and printed (with a team of helpers in parallel), and calls the right cook for each card.

In tinygrad the kitchen is a Compiled device, and "Device" is the reception desk that knows which kitchens exist. Data containers are Buffers. Everything below is just making those words precise.

The key ideaA device is a bundle of four pluggable parts: Compiled(device, allocator, renderers, runtime). Every backend — CPU, CUDA, AMD, Metal, WebGPU, the Python emulator, even the fake NULL device — is the same four-slot bundle with different parts plugged in. The rest of tinygrad never talks to hardware; it only talks to these four interfaces.

17.2The Device registry: names, DEV and lazy opening

Device is a singleton of class _Device. At import it does not import any backend — it just lists the files runtime/ops_*.py. A backend module is imported the first time someone indexes Device["CUDA"], and its class (by convention <Name>Device, found by a case-insensitive name match) is instantiated once and cached with functools.cache.

    return ret

  def default(self) -> Compiled: return self[self.DEFAULT]
  def get_available_devices(self) -> Iterator[str]:
    for device in ALL_DEVICES:

    assert (dev:=next((d for d in self._devices if d not in ["DISK", "NPY"] and getenv(d) == 1), None)) is None, \
      f"{dev}=1 is deprecated, use DEV={dev} instead"
    try:
      device = next(self.get_available_devices())
      os.environ["DEV"] = device   # we set this in environment for spawned children
      return device
    except StopIteration as exc: raise RuntimeError("no usable devices") from exc

Three details matter:

  • Canonical names. _canonicalize upper-cases the backend part and strips a trailing :0. So "cpu", "CPU" and "CPU:0" are the same device (and the same cached object), while "CPU:1" is a second instance of CPUDevice. This is what makes multi-device on one CPU possible (Chapter 19).
  • Selecting the default. Device.DEFAULT is DEV.device if DEV is set, otherwise the first backend in ALL_DEVICES = ["METAL", "AMD", "NV", "QCOM", "CUDA", "HIP", "CL", "CPU", "DSP", "WEBGPU"] that opens without raising. The old CUDA=1 style is now an assertion error telling you to use DEV=CUDA.
  • DEV is a Target. The env var is parsed by Target.parse as [interface[:indices]+]DEVICE[:RENDERER[:ARCH]]. DEV=CPU:LLVM keeps the CPU device but picks the LLVM renderer; DEV=PCI+AMD picks the PCI interface of the AMD driver. Several targets can be given separated by ;.

Read the constructor signature as the contract: device name, an Allocator instance, a list of Renderer classes (the first one that initialises wins, unless DEV names one), a Program class (runtime_t, may be None for HCQ backends, see §17.10) and an optional arch string. The compiler is not a constructor argument any more: it is self.renderer.compiler, because what you compile with depends on what you rendered (C source → clang, LLVM IR → LLVM, PTX → the CUDA driver…). A Program is anything with __init__(dev, TinyELF, links) and __call__(*args, global_size, local_size, wait).

Two more things every device has: a timeline buffer (16 bytes: [signal, last submitted value]) and an error_state buffer. synchronize() spins until timeline[0] ≥ timeline[1]. For the CPU nothing is asynchronous so this returns at once, but the same mechanism is what GPU queues signal into (§17.10). These are also the mysterious extra 16 + 8 bytes you will see in GlobalCounters.mem_used.

17.4Buffers: lazy handles to storage

A Buffer is not memory. It is a small Python object: (device, nbytes, options, offset, base) plus a slot _storage that is None until someone needs the bytes. The UOp graph refers to buffers (a BUFFER UOp's arg.buffer), the scheduler creates thousands of them, and the memory planner (Chapter 12) may decide most of them are views into one arena — so allocation is deferred to the last possible moment: ensure_allocated() inside exec_kernel/exec_copy.

  def is_allocated(self) -> bool: return self._storage is not None and (self._base is None or self._base_storage is self.base._storage)
  def ensure_allocated(self) -> Buffer: return self.allocate() if not self.is_allocated() else self
  def allocate(self, opaque=None, external_ptr=None) -> Buffer:
    assert not self.is_allocated(), "can't allocate already allocated buffer"
    if DEBUG >= 7: print(f"buffer: allocate {self.nbytes} bytes on {self.device}")
    # MAX_BUFFER_SIZE limits raw storage bytes (not logical elements).
    if not self.device.startswith("NULL") and self.nbytes > MAX_BUFFER_SIZE > 0 and self.options.external_ptr is None:
      raise RuntimeError(f"buffer of size {self.nbytes/1e6:.2f}MB is too large")
    if external_ptr is not None: self.options = replace(self.options, external_ptr=external_ptr)
    if self._base is not None:
      storage = replace(self.base.get_storage(), buf=self.allocator._offset(self.base._buf, self.nbytes, self.offset), maps={})
    elif opaque is not None:
      self.options = replace(self.options, nolru=True)
      if is_numpy_ndarray(opaque):
        if not opaque.flags.c_contiguous: opaque = opaque.copy(order='C')
        opaque = BufferStorage(addr:=opaque.ctypes.data, memoryview(opaque), MMIOInterface(addr, self.nbytes))
      elif isinstance(opaque, memoryview):
        opaque = BufferStorage(addr:=mv_address(opaque) if self.nbytes else 0, opaque, MMIOInterface(addr, self.nbytes))
      storage = opaque if isinstance(opaque, BufferStorage) else BufferStorage(opaque)
    else: storage = self.allocator.alloc(self.nbytes, self.options)
    storage = replace(storage, host=storage.host.view(self.offset, self.nbytes, fmt='B') if storage.host is not None else None)
    if self._base is None:
      if not self.device.startswith("DISK") and self.options.external_ptr is None:
        GlobalCounters.mem_used += self.nbytes
        GlobalCounters.mem_used_per_device[self.device] += self.nbytes
      if PROFILE: Buffer.profile_events.append(ProfilePointEvent(self.device, "alloc", self.trace_num, {"nbytes":self.nbytes}))
    self._storage, self._base_storage = storage, self.base._storage if self._base else None
    return self

  def deallocate(self):
    assert self._storage is not None, "buffer must be allocated to deallocate"
    if DEBUG is not None and DEBUG >= 7: print(f"buffer: deallocate {self.nbytes} bytes on {self.device}")
    if self._base is None:
      if GlobalCounters is not None and not self.device.startswith("DISK") and self.options.external_ptr is None:
        GlobalCounters.mem_used -= self.nbytes
        GlobalCounters.mem_used_per_device[self.device] -= self.nbytes
      if PROFILE: Buffer.profile_events.append(ProfilePointEvent(self.device, "free", self.trace_num))
      self.allocator.free(self._storage, self.nbytes, self.options)
    self._storage, self._base_storage = None, None

Things to notice in allocate:

  • Three sources of storage. A view (_base set) asks the allocator for _offset(base._buf, nbytes, offset) — on the CPU that is literally base + offset. An opaque object (a numpy array or memoryview you already own) is wrapped without copying and marked nolru. Otherwise allocator.alloc(nbytes, options).
  • What is a BufferStorage? A frozen dataclass (buf, meta, host, maps): buf is the device handle (an address for CPU, a CUdeviceptr for CUDA…), meta keeps any Python object alive (the mmap), host is an MMIOInterface if the CPU can read it directly, and maps caches this storage mapped into other devices (for peer access).
  • Accounting. Only base buffers count toward GlobalCounters.mem_used (views are free), and DISK buffers never count.
  • Limits. MAX_BUFFER_SIZE (env, bytes) raises early for oversized buffers — except on NULL, which has no real memory.

And the old copyin/copyout? Data enters a device through copy_from, which is not a memcpy but a tiny schedule: it builds a one-call LINEAR whose body is a STORE and runs it through the normal executor. That way "host → GPU", "GPU → GPU" and "disk → GPU" all go through one code path (exec_copy, or a copy queue on HCQ devices).

  def copy_from(self, src:Buffer) -> Buffer:
    assert self.nbytes == src.nbytes, f"copy size mismatch, {self.nbytes} != {src.nbytes}"
    assert self.is_allocated() and src.is_allocated(), "copy requires allocated buffers"
    from tinygrad.engine.realize import run_linear
    from tinygrad.uop.ops import UOp, Ops
    du, su = UOp.from_buffer(self, dtypes.uint8), UOp.from_buffer(src, dtypes.uint8)
    run_linear(UOp(Ops.LINEAR, src=(du.store_call(su),)), update_stats=False)
    return self

  def view(self, nbytes:int, offset:int) -> Buffer:
    assert offset < self.nbytes, "offset must be less than nbytes"
    return Buffer(self.device, nbytes, base=self.base, offset=self.offset+offset)

class Allocator(Generic[DeviceType]):
  lru = True

  def __init__(self, dev:DeviceType):
    self.dev: DeviceType = dev
    self.cache:dict[tuple[int, BufferSpec|None], list[tuple[BufferStorage, dict[Compiled, int]]]] = defaultdict(list)

  def alloc(self, size:int, options:BufferSpec|None=None) -> BufferStorage:
    assert size > 0, f"alloc size must be positive, getting {size}"

    # check if old most is free
    if (c:=self.cache[(size, options)]) and all(dev.timeline.host.view(fmt='Q')[0] >= freed_at for dev, freed_at in c[0][1].items()):
      return c.pop(0)[0]

    spec = options if options is not None else BufferSpec()
    try: return self._alloc(size, spec)
    except (RuntimeError, MemoryError): self.free_cache()
    try: return self._alloc(size, spec)
    except (RuntimeError, MemoryError) as e: raise MemoryError(f"Allocation of {size_to_str(size)} failed on {self.dev.device}. "
                                                               f"Used: {size_to_str(GlobalCounters.mem_used_per_device[self.dev.device])}") from e

  def free(self, storage:BufferStorage, size:int, options:BufferSpec|None=None):
    spec = options if options is not None else BufferSpec()
    if not LRU or not self.lru or spec.nolru or spec.external_ptr is not None: return self.do_free(storage, spec)

    # add that buf to cache
    users:list[Compiled] = [self.dev, *storage.maps] if storage.host is not None else []
    freed_at = {dev:dev.timeline.host.view(fmt='Q')[1] for dev in users if 'timeline' in vars(dev)}
    self.cache[(size, options)].append((storage, freed_at))

  def free_cache(self):
    for (_, options), storages in self.cache.items():
      for storage, _ in storages: self.do_free(storage, options if options is not None else BufferSpec())
      storages.clear()

  def do_free(self, storage:BufferStorage, options:BufferSpec):
    for dev in storage.maps: dev.synchronize()
    for dev, mb in storage.maps.items(): dev.allocator._unmap(mb)
    if options.external_ptr is None: self._free(storage, options)

  def map(self, buf:Buffer) -> BufferStorage: return self._map(buf.ensure_allocated())

  # implemented by the runtime
  def _alloc(self, size:int, options:BufferSpec) -> BufferStorage: raise NotImplementedError("need alloc")
  def _free(self, storage:BufferStorage, options:BufferSpec): pass  # if opaque is a Python object, you don't need a free
  def _copyin(self, dest, src:memoryview): raise NotImplementedError("need copyin")
  def _copyout(self, dest:memoryview, src): raise NotImplementedError("need copyout")
  def _map(self, buf) -> BufferStorage: raise NotImplementedError("need map")
  def _unmap(self, mb): pass  # default no-op; override if _map allocates iface-side state
  def _offset(self, buf, size:int, offset:int): raise NotImplementedError("need offset")

The public half (alloc, free, free_cache, map) is generic; a backend implements only the underscore half (_alloc, _free, _copyin, _copyout, _map, _offset). The cache is a dict (size, options) → [(storage, freed_at)]:

  • free doesn't free (unless LRU=0, the allocator sets lru=False, or the spec is nolru/external). It appends the storage with freed_at = the current "last submitted" value of each user device's timeline.
  • alloc pops the oldest cached entry of the same size and spec, but only if every device that used it has passed that timeline value (timeline.host[0] ≥ freed_at). On a GPU a buffer you "freed" may still be read by a kernel in flight — this check is what makes reuse safe without a synchronize.
  • Out of memory? _alloc raising RuntimeError/MemoryError triggers free_cache() (really release everything cached) and one retry, then a friendly MemoryError with the per-device usage.

HostAllocator (CPU, PYTHON, NPY, the NULL device's host buffers) implements _alloc as an anonymous mmap and _copyin/_copyout as plain slice assignment through an MMIOInterface:

17.7Loading and calling code on the CPU

After to_program, a CALL's body is a PROGRAM UOp with four sources: (SINK, LINEAR, SOURCE, BINARY) — the optimized AST, the linearized UOps, the rendered text, and the compiled bytes — and a ProgramInfo arg (launch dims, parameter slots, which slots are outputs/inputs, target). PROGRAM.to_elf() packages the binary into a TinyELF(lib, name, target, signature) and Device.runtime(elf) builds the backend's Program.

                                                                                              link_syms={n:p.buf.buf for n,p in self.links.items()})

  def __init__(self, dev:CPUDevice, obj:TinyELF, links:dict[str,CPUProgram]):
    self.dev, self.name, self.signature, self.profile_key, self.links = dev, obj.name, obj.signature, obj.profile_key, links
    self.lvp = obj.target.renderer == "LVP"
    self.packer = struct.Struct(''.join(unwrap(dt.fmt) for _, dt in TinyELF.iter_sig(self.signature)))
    if dev.remote is not None:

      self.fxn:Any = dev.remote.rpc(RemoteCmd.LOAD_PROG, len(obj.lib), len(link_ids), payload=obj.lib + link_ids)[0]
    else:

      loaded = self._load(obj.lib, self.buf.buf)
      unwrap(self.buf.host)[:len(loaded)] = loaded

      # RWX pages are unrepresentable on apple silicon (https://blog.svenpeter.dev/posts/m1_sprr_gxf/), so flip the written pages to R-X
      libc.mprotect(ctypes.c_void_p(self.buf.buf), len(obj.lib), libc.PROT_READ | libc.PROT_EXEC)

      # __clear_cache isn't a normal libc function, but a compiler support routine found in libgcc_s for gcc and compiler-rt for clang.
      # libgcc_s comes as shared library but compiler-rt is only a bunch of static library archives which we can't directly load, but fortunately
      # it somehow found its way into libSystem on macos (likely because it used __builtin_clear_cache) and libgcc_s is ~always present on linux
      # Using ["name"] instead of .name because otherwise name is getting mangled: https://docs.python.org/3.12/reference/expressions.html#index-5
      if 'rt' in DLL._loaded_: CPUProgram.rt_lib["__clear_cache"](ctypes.c_void_p(self.buf.buf), ctypes.c_void_p(self.buf.buf + len(loaded)))
      else:
        # msync should be a universal POSIX way to do this
        libc.msync(ctypes.c_void_p(self.buf.buf), len(loaded), libc.MS_SYNC | libc.MS_INVALIDATE)

      self.fxn = ctypes.CFUNCTYPE(None, ctypes.c_void_p)(self.buf.buf)

  def __call__(self, *args:int, global_size:tuple[int,int,int]=(1,1,1), local_size:tuple[int,int,int]=(1,1,1),
               wait:bool=False, timeout:int|None=None) -> float|None:
    hdr = 12 if self.lvp else 0
    kernargs = ctypes.create_string_buffer(hdr + len(args) * 8)
    if self.lvp: struct.pack_into('<3I', kernargs, 0, *data64_le(ctypes.addressof(kernargs) + hdr), len(args) * 2)
    self.packer.pack_into(kernargs, hdr, *args)
    if (remote:=self.dev.remote) is not None:
      ret = (remote._rpc if wait else remote._post)(remote.sock, RemoteCmd.EXEC_PROG, self.fxn, len(kernargs), int(wait), payload=bytes(kernargs))
      return ret[0] / 1e9 if ret is not None else None
    with cpu_profile(self.name, self.dev.device, profile_key=self.profile_key) as prof: self.fxn(kernargs)
    return float(unwrap(prof.en) - prof.st) * 1e-6 if wait else None

Step by step, for a local CPU:

  1. Allocate executable memory with the device's own allocator (nolru — code must not be recycled as data).
  2. Link it ourselves. jit_loader parses the ELF sections, lays out .text/.rodata into one image, and applies every relocation (x86-64 PC32/PLT32, AArch64 ADR_PREL_PG_HI21, CALL26…), creating trampolines for out-of-range calls into libm/libgcc. No dlopen, no temp files.
  3. W^X. Write the image, then mprotect it to read+execute (Apple Silicon refuses RWX pages) and clear the instruction cache.
  4. Wrap it as ctypes.CFUNCTYPE(None, c_void_p): every kernel takes one pointer — to a struct of its args. That is why the rendered C starts with struct E_2_4_args { float* arg0; float* arg1; };. __call__ packs buffer addresses (as u64) and integer variables into that struct with struct.Struct built from TinyELF.iter_sig.

def _compile_kernel(x:tuple[int, tuple[UOp, Renderer], dict]) -> tuple[int, UOp]:
  with Context(**x[2]): return x[0], to_program(*x[1])

def _get_call_to_compile(c:UOp) -> tuple[UOp, Renderer]|None:
  ast = c.body
  # a PROGRAM with a ProgramInfo and a BINARY is already compiled
  if (ast.op is Ops.SINK and isinstance(ast.arg, KernelInfo)) or \
     (ast.op is Ops.PROGRAM and not (isinstance(ast.arg, ProgramInfo) and ast.src[-1].op is Ops.BINARY)):
    return ast, Device[to_tuple(c.device)[0]]._select_renderer(HCQ_RUNTIME_DEV if isinstance(c.arg.aux, HCQInfo) else DEV)

def lower_and_compile(linear:UOp, verbose=True) -> UOp:
  # collect the kernels to lower and compile, deduped by their compile cache key
  if not len(ar:={c: a for c in linear.toposort() if c.op is Ops.CALL and (a:=_get_call_to_compile(c)) is not None}): return linear

  # lower and compile what's not cached, in parallel if there's a worker pool
  keys = {c: to_program_key(*a) for c, a in ar.items()}
  todo = list({keys[c]: a for c, a in ar.items() if keys[c] not in to_program_cache}.items())
  if len(todo):
    # kernels that beam search must compile in the parent, beam needs device access to time candidates

    pool = None if len(todo) == 1 or any(getattr(c.body.arg, "beam", 0) for c in ar) else get_worker_pool()
    ctx = {v.key: v.value for v in to_program_context}
    if CAPTURE_PROCESS_REPLAY: ctx["PROCESS_REPLAY_LOC"] = get_process_replay_loc()
    tasks = ((i, ast_ren, ctx) for i, (_, ast_ren) in enumerate(todo))
    try:
      with tqdm(total=len(todo), desc="compiling", disable=DEBUG<1 or not verbose) as pbar:
        for i, prg in (map if pool is None else pool.imap_unordered)(_compile_kernel, tasks):
          pbar.set_description(f"compiling {ansipad(prg.src[0].arg.name, 40)}")
          to_program_cache[todo[i][0]] = prg
          pbar.update(1)
    except KeyboardInterrupt:
      if pool is not None: terminate_worker_pool()
      raise

  # swap the compiled PROGRAMs into the calls
  return linear.substitute({c: c.replace(src=(to_program_cache[keys[c]], *c.src[1:])) for c in ar},
                           name="precompile kernels")
  • Dedup first. All CALLs whose body is still a kernel SINK (or an uncompiled PROGRAM) are collected and keyed by to_program_key; identical kernels — very common, e.g. the same layer applied twice — compile once.
  • Parallel. If more than one kernel is new, they go to get_worker_pool(): a spawn multiprocessing pool of PARALLEL workers (default = CPU count; 0 when VIZ is on) from engine/worker.py. Each worker runs the full codegen (to_program: optimize → lower → linearize → render → compile) with the parent's Context values (to_program_context) copied in, and with ALLOW_DEVICE_USAGE=0 — workers may compile but never open a device. BEAM search is the exception: it must time candidates on the real device, so BEAM kernels compile in the parent.
  • Swap in. Finally every CALL's body is substituted with its PROGRAM. The "compiling r_256_256_64_4 : 100%" bar you see at DEBUG≥1 is this loop.

def exec_copy(ctx:ExecContext, call:UOp, ast:UOp) -> list[float|None]:
  for bufs, device_vars in unwrap_multi(call, resolve_params(call, ctx.input_uops)):
    dest, src = bufs[0].ensure_allocated(), bufs[1].ensure_allocated()
    if dest.get_storage().host is not None and src.get_storage().host is not None:
      for b in (dest, src): b.allocator.dev.synchronize()
      with cpu_profile(f"{src.device} -> {dest.device}", f"{src.device}:COPY"): dest.host[:] = src.host[:]
    elif dest._host_mv() is not None: src.allocator._copyout(dest.as_memoryview(allow_zero_copy=True), src._buf)
    else: dest.allocator._copyin(dest._buf, src.as_memoryview(allow_zero_copy=True))
  return []

def exec_kernel(ctx:ExecContext, call:UOp, ast:UOp, devices=None) -> list[float|None]:
  ets:list[float|None] = []
  resolved = [_resolve(call.src[1+i], ctx.input_uops) for i in ast.arg.globals]
  for device, (bufs, device_vars) in zip(devices or to_tuple(get_call_arg_uops(call)[0].device), unwrap_multi(call, resolved)):
    if devices is None and device.split(":")[0] in HOST_DEVS: Device[device].synchronize(ctx.timeout)
    var_vals = {**ctx.var_vals, **device_vars, **{s.expr: s.arg.val for s in call.src[1:] if s.is_bound_var}}
    prg_bufs = {i:b.ensure_allocated() for i,b in zip(ast.arg.globals, bufs)}
    rt = get_runtime(device, ast, cache=ctx.cache)
    global_sz, local_sz = ast.arg.launch_dims(var_vals)
    try: args = [(var_vals[p.expr] if p.is_variable else _resolve(call.src[1+p.arg.slot], ctx.input_uops).val) if p.addrspace is AddrSpace.ALU else
                 prg_bufs[p.arg.slot].get_buf(device) for p in ast.kernel_params]
    except KeyError as e: raise RuntimeError(f"unbound Variable {e}") from None
    ets.append(rt(*args, global_size=global_sz, local_size=local_sz, wait=ctx.wait, timeout=ctx.timeout))
  return ets

exec_kernel is worth reading line by line: _resolve maps PARAMs to the caller's input UOps (the JIT uses this), unwrap_multi yields one lane per device for multi-device buffers (and binds _device_num), launch_dims evaluates symbolic global/local sizes with var_vals, and a missing variable becomes RuntimeError("unbound Variable …"). Finally rt(*args, global_size, local_size, wait) — and wait is true when DEBUG≥2, which is how the timing column of the DEBUG line gets real numbers.

17.9The PYTHON device: executing UOps one at a time

ops_python.py calls itself "the (living) definition of uops". Its renderer doesn't render text: PythonRenderer.render(uops) returns base64(pickle(uops)), the "compiler" decodes the base64, and PythonProgram unpickles the list of linearized UOps and interprets it. Every backend's semantics must match this interpreter, which is why it is the best way to understand what a linearized kernel means.

tinygrad/runtime/ops_python.py — PythonProgram (the main loop, abridged by line range)
class PythonProgram(Program['PythonDevice']):
  def __init__(self, dev:'PythonDevice', obj:TinyELF, links:dict[str,'PythonProgram']):
    self.uops: list[UOp] = pickle.loads(obj.lib)
    self.tensor_cores, self.links = PythonRenderer(obj.target).tensor_cores, links
    self.uop_to_index: dict[UOp, int] = {u:i for i,u in enumerate(self.uops)}
    self.loop_ends: dict[UOp, int] = {u.src[1]:i for i, u in enumerate(self.uops) if u.op in {Ops.END, Ops.BACKEDGE}}
  def __call__(self, *args, global_size:tuple[int,int,int]=(1,1,1), local_size:tuple[int,int,int]=(1,1,1), wait=False, **kw):
    st = time.perf_counter()
    warp = list(itertools.product(*[range(x) for x in local_size[::-1]]))
    warp_size = len(warp)
    for idxs in itertools.product(*[range(x) for x in global_size[::-1]]):
      values: dict[UOp, Any] = dict(env:=kw.get("env", ())) # a function runs with its params bound to the caller's args
      pargs: list[int] = list(args) # the PARAMs are first in the uops, in the args' order
      exec_masks = [[True] * warp_size]
      i = 0
      while i < len(self.uops):
        u = self.uops[i]
        src_values = [values[v] for v in u.src_without_body if v.dtype is not dtypes.void]
        src_dtypes = [v.dtype for v in u.src_without_body if v.dtype is not dtypes.void]
        if getenv("TRACE"): print(i, u.op, u.dtype, u.arg, src_values, src_dtypes)
        if u.op is Ops.BACKEDGE:
          i = self.uop_to_index[u.src[1]] if values[u.src[2]][0] else i+1
          continue
        if u.op is Ops.END:
          i = self.uop_to_index[u.src[1]]
          continue
        if u.op is Ops.STORE:
          assert len(src_values) == 2, f"STORE must be lowered to 2 srcs, got {len(src_values)}"
          store_gate = exec_masks[-1]
          for j,val in enumerate(src_values[1] if u.max_numel() > 1 else [src_values[1]]):
            for (m,o),v,g in zip(src_values[0], val, store_gate):
              if g: _store(m, o+j*_step(m, src_dtypes[1]), v, src_dtypes[1])
          i += 1
          continue
        if u.op is Ops.AFTER or (u.op is Ops.BITCAST and u.addrspace in (AddrSpace.GLOBAL, AddrSpace.LOCAL)): values[u] = src_values[0]
        elif u.op is Ops.PARAM and u.addrspace is AddrSpace.ALU: values[u] = [pargs.pop(0)] * warp_size
        elif u.op is Ops.RANGE:
          if u not in values: values[u] = [0] * warp_size
          else:
            for j in range(len(values[u])):
              values[u][j] += 1
          if values[u][0] == src_values[0][0]:
            del values[u]
            i = self.loop_ends[u] + 1
            continue
        elif u.op is Ops.STACK: values[u] = src_values

The model of execution:

  • Grid. For every global index idxs (outer itertools.product), the whole program runs once for a warp of all local threads in lock-step: every value is a list with one entry per lane. That's why the trace below shows [1.0] rather than 1.0.
  • A program counter i walks the list. RANGE initialises or increments its counter and, when it hits the bound, jumps past its END; END jumps back to its RANGE. IF/ENDIF push/pop an execution mask that gates stores.
  • Memory. A PARAM pops the next pointer from the args and views it as a typed memoryview; an INDEX produces (memoryview, offset) pairs; LOAD/STORE read/write them; a REG BUFFER is a fresh per-thread memoryview (an accumulator).
  • ALU. Everything in GroupOp.ALU is exec_alu(op, dtype, operands) — the same function the symbolic engine uses for constant folding (Chapter 6).

17.10HCQ: hardware command queues, as UOps

On a GPU the expensive part of launching a kernel isn't the kernel — it's the driver. Classic stacks go Python → runtime library (libcuda/HIP) → kernel driver ioctl → GPU for every launch. tinygrad's AMD, NV and QCOM backends instead talk to the GPU from user space: they map the GPU's command ring and doorbell into the process (via the kernel driver's KFD/nvidia ioctls, or even directly over PCI — see KFDIface/PCIIface in ops_amd.py, NVKIface/PCIIface in ops_nv.py), write packets themselves (AMD PM4/AQL, NVIDIA QMD/GPFIFO), and ring the doorbell. Synchronization is by signals: 64-bit memory words the GPU writes and the CPU (or another queue) waits on.

In this version that machinery is expressed in UOps (hcq_compile):

  1. prep — pm_unwrap_multi splits multi-device CALLs into one per device with _device_num bound; pm_insert_copy_staging inserts host staging buffers for copies that can't go peer-to-peer.
  2. batch — sched_batches groups consecutive HCQ calls and assigns each a queue (COMPUTE:0 for kernels, COPY:n for copies). A DepsTracker computes read/write overlaps between buffer byte ranges so a call waits only for the calls it truly depends on: wait/store (signal) instructions are inserted between queues, exec_barrier within a queue.
  3. encode — each backend's HWQueue subclass (AMDComputeQueue, NVComputeQueue, NullQueue…) turns every instruction into bytes of a command buffer (HWQueue.q appends words; values not known until run time become patches), and submit writes the ring/doorbell. The CUDA, CL and Metal backends "encode" into calls of their driver API instead (ccall(cuda.cuLaunchKernel, …)).
  4. lower + compile — the result is one kernel-like SINK named hcq_submit that is compiled for HCQ_RUNTIME_DEV (default CPU:LLVM) like any other kernel.
  5. link — hcq_link turns ALLOCs into real Buffers and GETADDRs into constant addresses, pre-writing everything that is known at link time into the command buffers so the per-run work is minimal.

The CPU then runs hcq_submit: wait for the previous run (fence on the timeline), patch the few run-time words (input addresses, variables), ring doorbells, bump the timeline. No Python per kernel. You can see this without a GPU on the NULL device, whose queue writes command words and whose "program" only emulates 1 µs timestamps:

17.13Hammer it again: edge cases and what breaks

  • Unbound variables. A kernel with a symbolic size launched without a value for its Variable fails in exec_kernel with RuntimeError: unbound Variable 'n' — values come from var_vals, bound per call (Chapter 18).
  • NULL can't read back. NullAllocator._copyout panics with "no copyout on NULL" unless NULL_ALLOW_COPYOUT=1: the NULL device never computes, so there is nothing true to read.
  • Workers can't open devices. Codegen runs with ALLOW_DEVICE_USAGE=0 (do_to_program is decorated with it, and so are pool workers): Device["CUDA"] inside a compile asserts. Only DISK, NPY and PYTHON are always allowed.
  • Asynchrony is invisible on CPU, not on GPU. exec_kernel synchronizes host devices before launching (HOST_DEVS), as_memoryview synchronizes before copying out, and the allocator's freed_at check prevents reuse of in-flight buffers. On a GPU without DEBUG=2, a kernel's time is not measured because wait=False.
  • Same kernel, two devices. runtime_cache is keyed by (program key, device): CPU and CPU:1 each load their own copy of the code, but compile it only once (to_program_cache doesn't care about the device index).
You run the same model twice in two separate Python processes on CPU. In the second process, which caches can save work?
to_program_cache and runtime_cache are module-level dicts. compile_cached uses sqlite at CACHEDB, so clang is skipped, but the Python-side codegen (optimize, lower, linearize, render) still runs.

The batch was encoded into command buffers at compile/link time; only run-time patches (input addresses, variables) and the doorbell write happen per run, inside native code.

Chapter summary

  • Device[...] lazily imports runtime/ops_x.py and caches one XDevice per canonical name ("CPU:0" ≡ "CPU"). DEV is a Target: device, renderer, arch, interface.
  • A device is Compiled(device, Allocator, [Renderer…], Program); the compiler belongs to the renderer.
  • Buffer = lazy handle; storage appears at ensure_allocated(); views are base+offset; data moves via copy_from (a 1-call STORE schedule) and as_memoryview.
  • Allocator.free caches storage per (size, spec); alloc reuses it only after the device timeline passed freed_at; OOM flushes the cache and retries.
  • run_linear = compile_linear (dedup + parallel to_program in a spawn pool, then hcq_compile) → link_linear → pm_exec dispatch (exec_copy / exec_kernel / exec_hcq / exec_validate).
  • CPU code is a clang ELF object linked in-process by jit_loader, made executable with mprotect, called through one struct-of-args pointer.
  • The PYTHON device interprets linearized UOps with a program counter, per-lane value lists and memoryviews — the reference semantics.
  • HCQ devices batch calls into a compiled host program (hcq_submit) that writes command buffers, waits/signals and rings doorbells.
  • The DEBUG=2 line: device, cumulative kernel #, name, #args, live memory, kernel time / running total, GFLOPS, unique|load-store GB/s.
