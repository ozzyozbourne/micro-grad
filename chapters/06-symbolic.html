CHAPTER 06Symbolic algebra & range analysis

Every tensor index in tinygrad starts as a messy integer expression. Movement ops, padding and optimizations multiply, add, divide and take remainders of loop counters. If that math reached the generated kernel unchanged, every load would pay for several integer divisions. This chapter covers the two tools that clean it up. The first is range analysis: every integer UOp knows a sound interval [vmin, vmax]. The second is symbolic: a few hundred PatternMatcher rules (Chapter 5) that use those intervals to fold constants, combine terms, and remove divisions and modulos. All before/after examples on this page are real captures from graph_rewrite(expr, symbolic).

6.1Intuition: index math is the hot path

Take a 4×6 tensor, view it as 2×2×6, swap the first two axes, view it as 4×6 again, and make it contiguous. Chapter 7 shows that each movement op rewrites the index used to read the input. The reshape back to 4×6 is the interesting one. To find where output element (r0, r1) lives in a 2×2×6 view, tinygrad first flattens: r0*6 + r1. It then peels the input coordinates off with // and %, innermost axis first: (r0*6+r1)%6, then (r0*6+r1)//6%2, then (r0*6+r1)//6//2%2 (this is _apply_reshape, §6.8). Run that unsimplified for every element of a large tensor and the kernel spends most of its time dividing. Here is the real kernel instead (section 7 of examples/06_symbolic.py):

The kernel optimizer split the loop, and symbolic proved that every // and % cancels. The last lines count UOps in the index graphs of five reshapes before and after simplification. The padded kernel shows the other job: a gate (0<Lidx0)&(Lidx0<5) stating where the index is valid (§6.9).

Analogy: simplifying an address formula once, not per letter A sorting office could compute "building = (street_number × 100 + house) ÷ 100" for every letter. Or it could notice once, on paper, that the formula is just street_number. Symbolic is that work on paper. It runs once per kernel at compile time, so the formula that runs for every element (every letter) is as cheap as possible.
The two halves Range analysis (UOp._min_max) answers "what values can this take?". Symbolic rules use the answer to justify rewrites. (x*4+y)//4 → x is only valid because the range of y is [0, 3]. Most clever folds in this chapter are some form of "the interval says the leftover is too small to matter".

6.2Range analysis: vmin, vmax and _min_max

UOp.vmin and vmax are thin properties over one functools.cached_property, UOp._min_max. Since UOps are hash-consed and immutable (Chapter 4), each node's interval is computed once and shared by everyone who builds the same expression. The computation is plain interval arithmetic, recursive over src, with one case per op:

6.3sint, Variables, bind and symbolic shapes

A shape dimension in tinygrad is a sint = int|UOp (ops.py:1885). Usually it is a plain int. When you want one compiled kernel for many sizes (a growing KV-cache, variable batch size), it can be a Variable. A Variable is not a special class (Variable = UOp). It is a scalar PARAM UOp whose arg carries a name and a value range:

  @staticmethod
  def variable(name:str, min_val:PyConst, max_val:PyConst, dtype:DType=dtypes.weakint) -> UOp:
    # a Variable is a scalar ALU PARAM with a name and a value range; binding it sets the val payload on the arg
    return UOp(Ops.PARAM, src=(UOp(Ops.STACK),), arg=ParamArg(-1, dtype, name=name, vmin_vmax=(min_val, max_val), addrspace=AddrSpace.ALU))
  @property
  def is_variable(self) -> bool:
    # a Variable is a scalar ALU PARAM that carries a value range
    return self.op is Ops.PARAM and self.arg.vmin_vmax is not None and self.arg.addrspace is AddrSpace.ALU and self._shape == ()
  @property
  def is_bound_var(self) -> bool:
    # a bound Variable is a Variable with the val payload set
    return self.is_variable and self.arg.val is not None
  @property
  def expr(self) -> str:
    assert self.op in {Ops.PARAM, Ops.BUFFER}
    return unwrap(self.arg.name)
  def bind(self, val:int|UOp):
    assert self.is_variable and not self.is_bound_var, f"op is {self.op}, need an unbound Variable"
    uval = UOp.const(val) if isinstance(val, int) else val
    assert uval.op is Ops.CONST, f"bind value must be a CONST, not {uval.op}"
    assert self.vmin <= uval.vmin and uval.vmax <= self.vmax, f"bind {val} not in range [{self.vmin}, {self.vmax}]"
    return self.replace(arg=replace(self.arg, val=uval.val))
  def unbound(self) -> Variable:
    assert self.is_variable, f"op is {self.op}, need Variable"
    return self.replace(arg=replace(self.arg, val=None))
  def unbind(self) -> tuple[Variable, int]:
    assert self.is_bound_var, f"can't unbind {self}"
    return self.unbound(), self.arg.val
  def unbind_all(self) -> tuple[UOp, dict[Variable, int]]:
    bound = {x: x.unbound() for x in self.backward_slice_with_self if x.is_bound_var}
    return self.substitute(bound, walk=True), {v: cast(int, x.arg.val) for x, v in bound.items()}
  • vmin_vmax is the whole point. It feeds the GroupOp.Defines branch of _min_max, so every expression built from the Variable gets a real interval, and every symbolic rule that asks "is the leftover smaller than the divisor?" can still answer.
  • bind(val) returns a different UOp (a new arg with val set), checked against the range. Bound and unbound Variables are different nodes in the hash-consing cache. unbind() returns (unbound_var, val), and the scheduler uses unbind_all to strip values out of a graph. The kernel is then cached for the unbound graph, and the values are passed at run time as var_vals.
  • sym_infer(var_vals) evaluates an expression for concrete values. It compiles the expression once into a Python function (_sym_fxn, using exec) and calls it:

6.4The rule stack: symbolic_simple ⊂ symbolic ⊂ sym

All of it lives in tinygrad/uop/symbolic.py and divandmod.py. The matchers are built in phases, each one adding to the previous with +:

phase 1 · symbolic_simple
pm_data_invalid + self folding (x+0, x*1, x//1), zero folding (x%x, x<x), constant folding (fold_const_alu), two-stage folding (x+c1)+c2, the divmod recombine, and cast/where cleanups. Cheap and local. Used almost everywhere in codegen.
phase 2 · symbolic
+ commutative (canonical operand order for index math), combining like terms, where folding, min==max → CONST, max folding, nested div, lt folding, moving consts to the end, and div_and_mod_symbolic. This is what UOp.simplify() uses.
phase 3 · sym
+ pm_simplify_valid (simplify under a gate), load/store folding, pow, reduce/mul chains and more "opinionated" rules. This is the full-strength version used by the codegen passes.

Where they run: the scheduler calls symbolic inside every reshape and pad (§6.8). UOp.simplify() and therefore resolve/ssimplify call symbolic. Codegen runs sym several times, as "initial symbolic", "postopt symbolic", "early symbolic" and "extra symbolic", and ends with "final symbolic":

def lt_folding(x:UOp, c:int) -> UOp|None:
  p, np = partition([u.pop_const(Ops.MUL) for u in x.split_uop(Ops.ADD)], lambda uf: uf[1] == 1)
  # d*y+p < c <=> y < ceildiv(c-p, d), so it folds when that bound is the same for p.vmin and p.vmax
  if np and (d:=math.gcd(*[int(f) for _,f in np])) > 1 and (t:=ceildiv(c-sum(u.vmin for u,_ in p), d)) == ceildiv(c-sum(u.vmax for u,_ in p), d):
    return UOp.usum(*[u*(f//d) for u,f in np])<t
  return None

lt_folding divides an inequality by the gcd of its non-unit coefficients. In 4x + y < 8, the coefficient-1 part p = y ranges over [0,3]. 6.6(x//c)*c + x%c → x: recombining div and mod

The identity \(\lfloor x/c\rfloor\cdot c + (x \bmod c) = x\) is everywhere in index math. Split an axis in two (an UPCAST opt, or a reshape followed by its inverse) and you get exactly this sum back. In practice the terms arrive scaled, shifted and mixed with other terms, so the rule is a small function rather than a pattern:

def _quotient_base(q:UOp, base:UOp, div:int) -> UOp|None:
  # the B with q == B//div and B%div == base%div, or None. only such congruence is needed to recombine, and canonicalization
  # moves consts freely: the quotient may be merged ((x//c + a)//div -> (x + a*c)//(c*div) for div>0) and shifted ((y + k*D)//D == y//D + k)
  (q, s), (num, a) = q.pop_const(), base.pop_const()
  if q.op is not Ops.DIV or q.src[1].op is not Ops.CONST: return None
  if div > 0 and num.op is Ops.DIV and num.src[1].op is Ops.CONST and q.src[1].val == (c:=num.src[1].val)*div: num, a, D = num.src[0], a*c, c*div
  elif q.src[1].val == div: D = div
  else: return None
  (x, xa), (p, pa) = num.pop_const(), q.src[0].pop_const()
  if p is not x or (t:=xa + a - pa) % D: return None
  return base - k*div if (k:=t//D - s) else base

def fold_add_divmod_recombine(x:UOp) -> UOp|None:
  # a scaled mod (base%div)*mul recombines with a partner q*(div*mul) carrying the quotient of a b == base (mod div):
  #   q == b//div     -> b*mul              (full recombine)
  #   q == (b//div)%d -> (b%(div*d))*mul    (partial recombine into a wider mod, needs d>0)
  terms = list(x.split_uop(Ops.ADD))
  for i,u in enumerate(terms):
    mod, mul = u.pop_const(Ops.MUL)
    if mod.op is not Ops.MOD or mod.src[1].op is not Ops.CONST: continue
    base, div = mod.src[0], mod.src[1].val
    for j,v in enumerate(terms):
      q, scale = v.pop_const(Ops.MUL)
      if i == j or scale != div*mul: continue
      rest = [t for k,t in enumerate(terms) if k not in (i,j)]
      if (b:=_quotient_base(q, base, div)) is not None: return (b*mul).usum(*rest)
      if q.op is Ops.MOD and q.src[1].op is Ops.CONST and (d:=q.src[1].val) > 0 and (b:=_quotient_base(q.src[0], base, div)) is not None:
        return ((b % (div*d))*mul).usum(*rest)
  return None

# Invalid poisons the value: ops move inside the gate so the Invalid reaches the LOAD/STORE and folds there.

It scans the terms of an ADD for a scaled mod (base % div) * mul. It then looks for a partner term whose scale is div*mul and whose core is a quotient of something congruent to base. When it finds one, the pair collapses to b*mul (full recombine). If the partner is itself (b//div)%d, the pair becomes a wider mod (b % (div*d))*mul (partial recombine). The game in §6.10 contains (x//4*4 + x%4 + 1) → (x+1): the extra term +1 goes into rest.

# NOTE: this cache is only on index UOps
@functools.cache
def fold_divmod_general(d: UOp) -> UOp|None:
  x, y = d.src

  if y.vmin==y.vmax==0: raise ZeroDivisionError(f"{'Division' if d.op is Ops.DIV else 'Mod'} by zero trying to rewrite {x.alu(d.op, y)}")
  # x//y is constant
  if d.op is Ops.MOD and (xdiv:=x//y).vmin == xdiv.vmax: return x - xdiv.vmin*y

  # split uops for the rest of the processing
  x_peeled, const = x.pop_const()
  uops_no_const = list(x_peeled.split_uop(Ops.ADD))

  # ** Constant Denominator Rules **
  # these rules strictly require y to be a scalar constant > 0
  if y.op is Ops.CONST and (c := y.val) > 0:
    # nested_div: (x%(k*c))//c -> (x//c)%k (requires k>0); the mod case is handled by remove_nested_mod below
    if d.op is Ops.DIV and x.op is Ops.MOD and (k := x.src[1].divides(c)) is not None and k.vmin > 0: return x.src[0] // y % k

    # remove_nested_mod in sum: (a%4 + b)%2 -> (a+b)%2
    if d.op is Ops.MOD:
      new_xs, changed = [], False
      for u in uops_no_const:
        if u.op is Ops.MOD and u.src[1].divides(c) is not None:
          u = u.src[0]
          changed = True
        new_xs.append(u)
      if changed: return (UOp.usum(*new_xs) + const) % y

    # exact division keeps the structure of x: (q*c+k)//c -> q+k//c
    if d.op is Ops.DIV and (q:=x_peeled.divides(c)) is not None: return q + const//c

    # Shared decomposition for folding rules
    decomp = [(u.divides(f:=u.const_factor()),f) for u in uops_no_const]
    terms, factors = zip(*decomp)

    # fold_divmod_congruence: fold if a is congruent to an expression whose range is between 0 and c
    # try both signs of the remainder for a lone term (covers a binary numerator that crosses one period)
    # or on an exact f%c == c//2 tie; otherwise pick the smaller to keep the product over terms small
    rem_choices = [(r, r-c) if (r:=f%c)*2 == c or len(terms)==1 else (min(r, r-c, key=abs),) for f in factors]
    for rems in itertools.product(*rem_choices):
      if (rem:=sum(r*v for r,v in zip(rems,terms))+const%c).vmin//c==rem.vmax//c:
        if d.op is Ops.MOD: return rem - rem.vmin//c*c
        return sum((f-r)//c * v for f,r,v in zip(factors,rems,terms)) + const//c + rem.vmin//c

    # nest_by_factor: x//c -> (x//f)//(c//f), x%c -> (x//f%(c//f))*f + b where b=x%f
    # f is a term factor dividing c or the gcd of all factors and c
    # DIV identity holds for any sign of x; MOD reconstruction needs x.vmin>=0
    results = []
    for div in {abs(f) for f in (*factors, math.gcd(*factors, c)) if 1 < abs(f) < c and c%f==0}:
      if (newxs := fold_divmod_general(x//div)) is not None:
        if d.op is Ops.DIV:
          results.append((len(newxs.backward_slice), newxs // (c // div)))
        elif x.vmin >= 0 and newxs.vmin >= 0:
          b_parts = [f%div*t for f, t in zip(factors, terms) if f%div]
          if const % div: b_parts.append(x.const_like(const % div))
          b = UOp.usum(*b_parts) if b_parts else x.const_like(0)
          if 0 <= b.vmin and b.vmax < div:
            results.append((len((r:=(newxs % x.ufix(c//div))*div + b).backward_slice), r))
    if results: return min(results, key=lambda r: r[0])[1]

  # ** Variable Denominator / Fallback Rules **
  # These rules apply to variables OR constants that failed the checks above.
  # Reconstruct all uops including const for these checks.
  all_uops = list(x.split_uop(Ops.ADD))

  # divide_by_gcd: x//y -> (x//gcd)//(y//gcd)
  gcd = UOp.gcd(*all_uops, y).simplify()
  if not (gcd.op is Ops.CONST and gcd.val==1):
    ret = unwrap(x.divide_exact(gcd)).alu(d.op, unwrap(y.divide_exact(gcd)))
    return ret*gcd if d.op is Ops.MOD else ret

  # factor_remainder: (d*x+y)//d -> x+y//d
  if y.vmin<0 or x.vmin<0: return None
  quo, rem = [], []
  for u in all_uops:
    if (q:=u.divide_exact(y)) is not None: quo.append(q)
    elif y.op is Ops.CONST and (c:=u.const_factor())%y.val!=c:
      rem.append(u.divides(c)*(c%y.val))
      quo.append(u.divides(c)*(c//y.val) if d.op is Ops.DIV else u.const_like(0))
    else: rem.append(u)

  if not quo: return None
  new_x = sum(rem)+x.const_like(0)
  if new_x.vmin<0: return None
  return new_x%y if d.op is Ops.MOD else new_x//y+sum(quo)

6.8Where the divs and mods come from: _apply_reshape

A reshape changes how a flat element number is split into coordinates. The scheduler's definition of the movement ops (apply_movement_op, Chapter 7/10) maps output loop ranges to input index expressions. For RESHAPE it flattens with the output strides and re-splits with the input shape:

@functools.cache
def _apply_reshape(in_shape:tuple[sint,...], out_shape:tuple[sint, ...], urngs:UOp) -> UOp:
  acc:sint = 1
  axes_in:list[UOp] = []
  for s,src in list(zip(out_shape, urngs.src))[::-1]:
    axes_in.append(acc*src)
    acc *= s
  combined_axes = UOp.const(0).usum(axes_in)
  axes_out:list[UOp] = []
  for s in in_shape[::-1]:
    axes_out.append(combined_axes % s)
    combined_axes //= s
  # this simplify is doing a lot of heavy lifting. this is the replacement for the reshape view merging code
  return graph_rewrite(UOp.sink(*axes_out[::-1]), symbolic+pm_simplify_valid+pm_drop_and_clauses, name="reshape")

6.9Invalid and gated indices

PAD creates indices that are only sometimes valid. tinygrad represents "index i, valid when cond" as cond.where(i, Invalid), where Invalid is a special constant (UOp.invalid / valid / get_idx / get_valid):

  def invalid() -> UOp: return UOp.const(Invalid)
  def valid(self, cond) -> UOp: return cond.where(self, self.const_like(Invalid))

Two rule families keep gated indices clean:

  • pm_data_invalid (the first part of symbolic_simple) treats Invalid as poison that must reach the LOAD/STORE. Arithmetic moves inside the gate, cond.where(x, Invalid) + 1 → cond.where(x+1, Invalid), so that 0 * maybe_invalid is never folded to 0 and the gate is never lost. An INDEX whose index is plain Invalid becomes "no load" (the alternative value, or 0) or "no store".
  • pm_simplify_valid (part of sym) simplifies the index under the assumption that the gate holds. uop_given_valid parses each clause like r0<4 into bounds, substitutes a fake Variable with the narrower range, simplifies, and substitutes back. simplify_valid does the same to the clauses of the gate itself, using each other.

6.11Soundness, cost and pitfalls

  • Every rule is guarded by range facts or fits. Combining terms checks that the new coefficient fits the dtype, and moving constants checks no_overflow. Folding (x//c1)//c2 requires c2 > 0, because floor division by a negative number does not nest that way. These guards are why symbolic can run on real-dtype expressions late in codegen, not just on weakint indices.
  • Loose intervals cost folds, never correctness. (x//4*4 + x%4) has interval [0, 103]. The true range is [0, 100], but interval arithmetic does not know the two terms are correlated. A loose bound can only make a rule decline. That is why structural rules such as recombine exist next to the interval rules.
  • Division by a range that includes 0 sends _min_max to the dtype bounds, and fold_divmod_general raises ZeroDivisionError when the divisor is exactly 0.
  • Cost. fold_divmod_general is functools.cached, which is safe because UOps are immutable and hash-consed. Its nest_by_factor branch recurses and keeps the result with the smallest backward_slice. Symbolic is one of the hottest parts of compile time, which is why match stats and the compiled UPat matchers from Chapter 5 matter.
  • Order sensitivity. Many rules expect canonical forms (consts last, commutative order). A rule that does not seem to fire on a hand-built expression may just be seeing the operands in a different order, so run .simplify() on the inputs first.

def which_branch(d: UOp) -> int:

  code, depth, line = divandmod.fold_divmod_general.__wrapped__.__code__, [0], [0]

        if depth[0] == 1: line[0] = frame.f_lineno

  finally: sys.settrace(None)

def rule_name(p: UPat, fn) -> str:
  # a named function, else the rule's trailing comment, else the nearest comment above it
  if fn.__name__ != "<lambda>": return fn.__name__
  if "#" in (t := linecache.getline(p.location[0], p.location[1])): return t.split("#", 1)[1].strip()
  above, ln = [], p.location[1] - 1   # the block of comment lines directly above the rule
  while (t := linecache.getline(p.location[0], ln).strip()).startswith("#"): above.insert(0, t); ln -= 1
  # prefer a plain comment (not a NOTE/TODO, commented-out code or a "** section **" header), else a section header
  plain = [t.strip("# ") for t in above if not t.startswith("# **") and not any(w in t for w in ("NOTE", "TODO", "UPat"))]

Chapter summary

  • _min_max gives every UOp a cached, sound interval: one rule per op (ADD sums, MUL corners, DIV corners when the divisor's sign is fixed, MOD by a constant "same period or wrap", CMPLT as a bool interval, WHERE as a union). The fallback is the dtype's bounds.
  • Variables are scalar PARAMs with vmin_vmax, so their intervals feed every rule. bind makes a different UOp and unbind_all strips values for caching. sym_infer evaluates, and resolve turns a symbolic comparison into a Python bool when the range decides it.
  • symbolic_simple ⊂ symbolic ⊂ sym: local folds; then canonical order, combining terms, lt/nested-div/max folding, "min==max → CONST" and div_and_mod_symbolic; then valid/gate simplification.
  • fold_divmod_general tries, in order: constant quotient, nested_div, remove_nested_mod, exact division, congruence, nest_by_factor, divide_by_gcd and factor_remainder. Most branches come down to "does the leftover's interval fit in one period?".
  • Reshape = naive div/mod + simplify. _apply_reshape replaced the old view-merging code, and the kernel's index cost is whatever symbolic could not cancel.
  • Invalid gates PAD indices. pm_data_invalid keeps the poison attached, and pm_simplify_valid simplifies indices under their gate.
